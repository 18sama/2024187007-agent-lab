# 医疗对话整理规则

## 1. 说话人识别
- 每行格式：`说话人：内容`（冒号为半角 `:` 或全角 `：`）。
- 医生侧同义称呼：`医生`、`大夫`、`Doctor`、`Dr.`。
- 患者侧同义称呼：`患者`、`病人`、`Patient`。
- 无法识别的说话人标记按原文保留，归入"其他"，不强行猜测。

## 2. 问答配对规则
- 按对话**时间顺序**扫描。
- 一段**连续的**患者发言合并为一个"问题"（可含多句）。
- 紧跟其后的一段**连续的**医生发言合并为一个"回答"。
- 一个"问题 + 回答"组合构成一条问答记录，从 1 开始编号。
- 若患者发言之后没有医生回答（对话以患者发言结束，或被下一位患者发言打断），
  该问题标注为 `（未回答）`。

## 3. 输出格式
```markdown
# 医疗对话问答记录

## 问题 1
- **患者问**：……
- **医生答**：……

## 问题 2
- **患者问**：……
- **医生答**：（未回答）
```

## 4. 红线：不得增补信息
- 只做格式转换与归类，**不补充**原始资料中没有的内容。
- **不推断**诊断、不补充医学建议、不解释医学术语、不扩写患者主诉。
- 原文措辞尽量保留；仅允许修正明显的标点/换行，不做语义改写。
- 若原文有信息缺失（如未回答），如实标注，而非补全。

## 5. 异常处理
- 空行忽略。
- 无说话人标识的行：若紧跟在前一句之后，视为上一说话人的续句；否则保留原文并提示。
- 输入为空或只有空行：输出空记录并提示"未检测到有效对话"。
