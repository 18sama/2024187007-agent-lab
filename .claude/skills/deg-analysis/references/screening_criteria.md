# 差异基因筛选标准

本 Skill 采用以下默认标准判定"差异表达基因（DEG）"：

| 条件 | 阈值 | 含义 |
| --- | --- | --- |
| 校正后 P 值 | `padj < 0.05` | 控制 FDR 在 5% 以内（BH 校正） |
| 倍数变化 | `abs(log2FoldChange) >= 1` | 表达量变化至少 2 倍（log2 尺度 ±1） |

## 分类
- **上调（Up）**：`padj < 0.05` 且 `log2FoldChange >= +1`（肿瘤中高表达）。
- **下调（Down）**：`padj < 0.05` 且 `log2FoldChange <= -1`（肿瘤中低表达）。
- **不显著（NS）**：其余基因。

## 说明
- 同时满足两个条件才判定为差异表达，兼顾**统计显著性**与**生物学效应大小**。
- 阈值可在脚本中按需调整，但修改后必须在结果说明中注明新的标准。
- 结果表保留全部基因的完整统计量（不预先截断），方便按不同阈值复现。
