# 医疗对话整理（medical-dialog-qa）

## 适用任务
- 输入：一段含说话人标识的医疗对话文本（如 `医生：…` / `患者：…`）。
- 输出：结构化的问答记录（Markdown），按时间顺序编号，逐条对应"患者提问 → 医生回答"。

## 输入输出
| 类型 | 路径约定 | 说明 |
| --- | --- | --- |
| 输入 | `examples/input_dialog.txt` | 原始对话，每行一句，以"说话人："开头 |
| 输出 | `--out` | 生成的问答记录 Markdown 文件 |

## 参考资料的读取条件
- 处理前先读 `references/processing_rules.md`，了解说话人识别规则、问答配对规则与"不得增补信息"的红线。

## 脚本调用方法
```bash
python scripts/process_dialog.py \
  --input <input_dialog.txt> \
  --out <output_qa.md>
```

## 处理规则概要（详见 references/processing_rules.md）
1. 识别说话人（医生/患者，支持同义称呼）。
2. 连续的"患者发言"作为问题，其后连续的"医生发言"作为回答，配对成一条问答记录。
3. 若患者发言后没有医生回答，标注"（未回答）"。
4. 只做格式转换，不补充、不推断、不改写原始内容。

## 结果核验要求
- 输出中的每一句话都必须能在输入原文中找到对应，不得新增事实。
- 问答编号连续、说话人正确、顺序与原文一致。
