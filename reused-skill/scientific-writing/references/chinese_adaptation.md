# 中文课程报告适配说明（本次改造新增）

本文件为改造 scientific-writing Skill 时新增的参考文档，用于将该 Skill 面向
英文期刊的写作规范适配到中文课程实验报告场景。

## 1. 保留的核心能力
- IMRAD 结构：引言（背景/目标）→ 方法 → 结果 → 讨论/结论。
- 图表规范：每张图/表需有自说明标题、标注坐标轴单位与样本量。
- 引用规范：数值与结论需可溯源，方法需注明依据。

## 2. 面向中文课程报告做的调整
- 语言：正文使用中文，专业术语首次出现时给出英文原文（如"负二项分布
  Negative Binomial"）。
- 结构：课程报告可保留"实验目的 / 环境 / 步骤 / 结果 / 讨论 / 结论"的
  编号结构，不必严格照搬期刊论文的 Abstract 写作。
- 引用：以教材、官方文档与数据来源（如 GDC/TCGA）为主，采用顺序编号标注。
- 语气：允许使用第一人称"本实验 / 我"叙述过程，结论需与实验证据对应。

## 3. 不得违背的红线
- 不编造数据与引用；所有数值来自脚本实际运行结果。
- 结果与讨论分离：先客观呈现结果，再作解释，不夸大结论。
